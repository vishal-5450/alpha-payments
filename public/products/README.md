# Product media

Drop screenshots and logos here. Prefer SVG for logos; PNG/WebP for screenshots.

## Screenshots (home + /products)

Filenames must match product slugs. `ProductMedia` loads `{slug}.png` and falls back to the built-in mock UI if the file is missing.

| Product | Path |
| --- | --- |
| ISO Genie | `iso-genie.png` (or `.svg` / `.webp` — currently PNG) |
| API Genie | `api-genie.png` |
| INSIGHT | `insight.png` |
| Decipher | `decipher.png` *(optional — mock UI used until you add one)* |

## Product logos (optional, for later)

When ISO Genie / API Genie logos are approved, put them here:

| Asset | Path |
| --- | --- |
| ISO Genie logo | `logos/iso-genie-logo.svg` (PNG also fine) |
| API Genie logo | `logos/api-genie-logo.svg` |
| INSIGHT logo | `logos/insight-logo.png` *(already present)* |
| Decipher logo | `logos/decipher-logo.svg` |

Tips: transparent background, crisp at ~120–240px wide for logos; screenshots look best around 1280–1600px wide.
