# Partner logos

Put one file per brand in this folder. Prefer **SVG**, then PNG / WebP.

The chips look for (in order):

1. `{slug}.svg`
2. `{slug}.png`
3. `{slug}.webp`

If no file is found, a lettermark is shown (no broken-image icon).

| Brand | Filename |
| --- | --- |
| RuPay | `rupay.svg` or `rupay.png` |
| NPCI | `npci.svg` or `npci.png` |
| Postilion | `postilion.svg` or `postilion.png` |
| Base24-eps | `base24-eps.svg` or `base24-eps.png` |
| ACI Worldwide | `aci-worldwide.svg` or `aci-worldwide.png` |
| HPE NonStop | `hpe-nonstop.svg` or `hpe-nonstop.png` |
| Visa | `visa.svg` or `visa.png` |
| Mastercard | `mastercard.svg` or `mastercard.png` |

Tips: transparent background, ~120–240px wide, readable at about 28px tall. Official brand SVGs from each partner’s brand portal look best.
